# Gerar APK grátis pelo GitHub Actions

1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste projeto para o repositório.
3. Vá em **Actions**.
4. Selecione **Build Android APK**.
5. Clique em **Run workflow**.
6. Quando terminar, abra a execução e baixe o artefato **music-player-debug-apk**.
7. Dentro do ZIP baixado estará o arquivo `app-debug.apk`.

Este workflow gera uma versão Debug, adequada para instalar e testar no Android.
